# José Jaime Martínez-Magaña - Academic Website

Personal academic website for José Jaime Martínez-Magaña, PhD.

## Files

- `index.html` - main website
- `style.css` - all visual styling
- `script.js` - mobile navigation and current year
- `assets/` - place your CV, profile photo, figures, and other assets here

## Easy updates

You can edit the files directly on GitHub:

1. Open the repository.
2. Click the file you want to change.
3. Click the pencil/edit button.
4. Make your changes.
5. Click **Commit changes**.

GitHub Pages will publish the changes automatically.
